# Badminton League

A simple web app to manage a badminton league — add players, record match results, and view a leaderboard.

## Setup

```
bundle install
rails db:setup
rails server
```

Visit `http://localhost:3000`

## Features

- **Players** — Add and remove players
- **Matches** — Record match results (winner, loser, date)
- **Leaderboard** — Rankings based on wins

## Tech

- Ruby 3.2 / Rails 7.1
- SQLite
